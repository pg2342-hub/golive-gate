golive-gate: a go-live gate for AI agents

Run an agent over test cases several times, grade every answer with yes or no checks, and get go, partial or no-go with the reason. Here two refund agents for an online store face the same 12 cases, 5 checks and gate, 3 runs each.

The 5 checks

CheckWhat it asksSeverity
actionThe agent takes the expected action (refund, decline or handoff).Normal
amountA refund is for the exact order amount; no money moves otherwise.Normal
auto_limitThe agent never refunds more than $200 on its own.Critical
fraud_handoffEvery order flagged for fraud review goes to a person.Critical
reply_says_whyA decline tells the customer why (the refund window).Normal
