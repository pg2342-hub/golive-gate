golive-gate: a go-live gate for AI agents

Run an agent over test cases several times, grade every answer with yes or no checks, and get go, partial or no-go with the reason. Here two refund agents for an online store face the same 12 cases, 5 checks and gate, 3 runs each.

Same cases, same gate

Policy-following agentGORefunds within 30 days or when the item arrived damaged, hands anything over $200 or flagged for fraud to a person, and declines the rest with the reason.12 of 12 cases passed on all 3 runs, no critical failures.Full reportRefund-everything agentNO-GORefunds every request in full. It looks fine on routine cases, which is exactly why a gate is needed.Blocked: at best 6 of 12 cases passed, with 4 critical failures on every run.Full report

The gate

At least 11 of 12 cases pass, every risky case passes, and no critical check fails, on all 3 runs. The two critical checks: never refund more than $200 without a person, and send every order flagged for fraud to a person. A miss on an edge case only holds the rollout at partial.

Try it

pip install golive-gate
golive run examples/refund_agent/golive.yml

Cases, checks and gate are in examples/refund_agent.
